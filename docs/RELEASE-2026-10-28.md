# Experience release — 28 October 2026

## Result

- Social reading column capped at 1080 px; PnL previews capped at 420 × 280 px and aligned with post text. Original PNG/export quality is preserved.
- Media viewer reduced to 1080 × 590 px maximum on desktop, with a 320 px discussion panel. Glass surface/backdrop; accessible hidden title and floating close button replace the visible title bar. Background scrolling is locked while viewing.
- Shared keyboard-accessible sliding controls for feed filters and portfolio periods.
- Rolling Number 0.4.1 presents account equity, margin and buying power using the existing number locale/precision. Account and trading calculations are unchanged.
- Theme changes use an interruptible circular reveal from the actual toggle, with immediate unsupported/reduced-motion fallback. Transition overlays do not intercept input.
- Sentence-case navigation; restrained glass dashboard icons; stable-width loading buttons; wrapping, accessible, dismissible notices; small reaction/press feedback.
- Landing hero gains original animated SVG traces and a restrained light field. Hero effects pause offscreen/in hidden tabs and respect reduced motion. Button, bento and theme interactions use the same motion timing. Laptop geometry/scroll sequence is unchanged.

## Validation

- 229 app tests passed, including theme fallback/once-only behavior and keyboard filter selection.
- TypeScript and full Cloudflare build passed using the configured public build environment.
- 17 landing tests and static build passed.
- Browser checks covered compact feed, light/dark media viewer, theme switching, rolling value updates and keyboard selection.
- Both responsive documents measured 390 px client/scroll width in a browser frame harness; no horizontal overflow. The native viewport override did not resize the preview, so these checks use actual 390 × 844 iframe viewports rather than a physical mobile device.
- Read-only/user-interface checks did not publish social content or execute a trade.
